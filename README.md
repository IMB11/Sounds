**It's what it says on the tin.**

Sounds is a mod that adds a variety of new sound effects to the game, whilst improving existing ones that didn't quite fit. It's a game-changer, it makes vanilla feel incomplete in comparison.

The mod is also a spiritual continuation of ExtraSounds, Auditory and QualitySounds; the majority of features from these mods have been expanded upon to be highly configurable.

## Features
- **Includes over 170 new sound effects** which span across the entire game, such as UI, chat messages, in-game actions and block sounds.
- **High quality** sound effects sourced from [Zapsplat](https://www.zapsplat.com/) and hand-tweaked for the best SFX experience.
- **Fully client-side only**, no need to install on the server!
- **Highly customizable**, you can change the sounds events used, and even tweak the dynamic block and item sounds through resource packs, especially useful for creating addons for content mods.'

## Configuration
As mentioned, Sounds is **highly customizable** - the simple effects can be edited either through the configuration found in the `config/sounds/` folder of your game instance, or though the configuration screen.

*[Mod Menu](https://modrinth.com/mod/modmenu) is required to access the configuration screen for the Fabric version of the mod.*
